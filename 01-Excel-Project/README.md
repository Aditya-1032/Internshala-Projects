# Social Media Analytics for Strategic Branding

**Project Type:** Data Analytics  
**Training Program:** Internshala Data Science Training  
**Tools:** Microsoft Excel, Excel Power Query

## 1. Project Overview

This project was completed as part of my Data Science training with Internshala Trainings. It focuses on analyzing social media marketing performance using Excel and a provided PepsiCo marketing dataset.

The project follows a business scenario in which a Data Analyst evaluates social media activities across platforms such as Instagram, Facebook, Twitter, and YouTube to understand audience engagement, content performance, campaign effectiveness, and follower growth.

The objective is to transform raw social media data into meaningful insights that can support data-driven marketing decisions.

## 2. Business Problem

With marketing activities spread across multiple social media platforms and campaigns, businesses need a consolidated view of their digital marketing performance.

This project addresses key questions:

- Which content types generate the highest engagement?
- Which platforms perform best?
- How effectively is the advertising budget being utilized?
- Which hashtags and campaigns perform well?
- What patterns can be observed in follower growth and audience retention?
- How can social media marketing strategies be improved using data?

## 3. Project Objectives

- Clean and prepare social media data for analysis.
- Calculate and compare engagement metrics across platforms.
- Identify high-performing posts, hashtags, and content types.
- Evaluate marketing campaign effectiveness.
- Analyze weekly follower growth and audience retention.
- Explore the relationship between advertising spend and follower growth.
- Develop data-driven marketing recommendations.

## 4. Dataset Description

The assignment provides three datasets.

### A. Posts Dataset

Contains individual social media post information, including:

- Post ID, platform, and publication date
- Content type and caption
- Likes, shares, and comments
- Impressions, reach, and clicks
- Hashtags used and campaign name

### B. Engagement Summary Dataset

Contains weekly platform-level performance data, including:

- Week start date and platform
- New followers and unfollows
- Total followers
- Engagement rate
- Advertising spend

### C. Campaign Metadata Dataset

Contains campaign information, including:

- Campaign name and dates
- Campaign objective
- Total allocated budget
- Target platforms
- Primary hashtags

## 5. Project Tasks and Analysis

The assignment is divided into seven tasks.

### Task 1: Data Preprocessing and Cleaning

- Remove duplicate post entries.
- Standardize date formats and platform names.
- Ensure numeric columns have appropriate formatting.
- Split hashtags into individual tags.

**Tools:** Excel Power Query, Excel data preparation features.

### Task 2: Engagement Analysis

- Calculate average engagement rates by platform.
- Identify the top 10 posts with the highest engagement.
- Create PivotTables for total likes, shares, and comments by content type and platform.
- Calculate average clicks per post by hashtag.
- Rank top-performing hashtags using formulas.

**Engagement Rate Formula:**

`Engagement Rate = (Likes + Shares + Comments) / Impressions`

**Tools:** Excel formulas, PivotTables, ranking formulas.

### Task 3: Social Media Platform Analysis

- Identify the platform generating the highest engagement.
- Compare follower growth rates across platforms.
- Visualize engagement in relation to advertising spend.
- Recommend whether to prioritize one or two core platforms or maintain a multi-platform strategy, based on the analysis.

**Tools:** Excel formulas, PivotTables, charts.

### Task 4: Hashtag and Content Strategy

- Identify the most frequently used hashtags.
- Calculate average likes and comments for posts containing each hashtag.
- Compare video, image, and carousel performance across platforms.
- Recommend which content types should be prioritized on each platform.

**Tools:** Excel formulas, PivotTables, comparative analysis.

### Task 5: Campaign Effectiveness

- Calculate total and average impressions, likes, and clicks per campaign.
- Calculate engagement uplift during campaigns compared with the period before each campaign.
- Evaluate campaign engagement relative to advertising budgets.
- Identify campaigns with the highest engagement return relative to budget.
- Identify campaigns with the strongest follower growth impact.

**Tools:** Excel formulas, campaign-level comparisons.

### Task 6: Follower Retention and Audience Loyalty

- Visualize weekly follower growth trends by platform using line charts.
- Identify the week with the highest net follower gain.
- Create moving-average charts to smooth follower growth trends.
- Investigate the relationship between advertising spend and follower growth using scatter plots and correlation calculations.

**Tools:** Excel formulas, line charts, scatter plots, moving averages, correlation analysis.

### Task 7: Findings and Actionable Recommendations

- Summarize the key findings from the analysis.
- Provide data-backed recommendations for social media marketing.
- Suggest improvements to campaign planning, content performance, platform selection, and marketing return on investment.

**Deliverable:** A video presentation explaining the findings and recommendations in my own words.
