# Internshala Projects – Data Science & Analytics

Welcome to my **Internshala Projects** repository! This repository showcases projects completed as part of my Data Science training, applying statistical knowledge, data analytics, Python programming, SQL, Excel, Power BI, and machine learning to practical business problems.

The projects demonstrate my learning journey across data cleaning, exploratory data analysis, customer behavior analysis, database querying, predictive modelling, and interactive dashboard development.

## About This Repository

As a Statistics postgraduate with an interest in research-driven and analytical roles, I created this repository to document my practical work, strengthen my technical skills, and demonstrate how data can be transformed into meaningful insights for business decision-making.

Each project folder contains its own README with the project overview, objectives, tools, methodology, key findings, and relevant files.

## Projects

### 1. Social Media Analytics for Strategic Branding – Excel

**Tools:** Microsoft Excel, Power Query

Analyzed social media campaign performance to understand engagement, audience loyalty, follower growth, campaign effectiveness, and return on investment (ROI).

**Key areas:**
- Campaign performance analysis
- Engagement rate and uplift calculations
- Follower retention and audience loyalty
- ROI analysis
- Data summarization and visualization

[View Project](./01-Excel-Project/)

### 2. Retail Customer Retention Analytics – TESCO

**Tools:** Power BI, DAX, Data Modeling

Developed a retail analytics project focused on customer behavior, retention, loyalty, churn, and customer lifetime value.

**Key areas:**
- Customer segmentation and loyalty tiers
- Customer lifetime value (CLV)
- Churn and retention analysis
- Promotional effectiveness
- Store performance and interactive dashboards

[View Project](./02-Power-BI-Project/)

### 3. Logistics Optimization for Delivery Routes – Amazon

**Tools:** SQL, MySQL

Used SQL queries to analyze logistics and delivery operations, exploring routes, warehouses, delivery agents, orders, and shipment tracking data.

**Key areas:**
- Relational data analysis
- Joins and aggregations
- Delivery route and warehouse analysis
- Shipment tracking
- Logistics performance insights

[View Project](./03-SQL-Project/)

### 4. Financial Risk Analysis – Barclays

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

Analyzed financial transactional survey data to explore customer activity, account balances, transaction patterns, and potential risk indicators.

**Key areas:**
- Data cleaning and preprocessing
- Descriptive transaction analysis
- Customer profiling
- Financial risk identification
- Data visualization and hypothesis testing

[View Project](./04-Python-Financial-Risk-Analysis/)

### 5. Market Basket Analysis with Python – Amazon

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Analyzed Amazon customer survey data to investigate shopping behavior, purchase categories, satisfaction, cart abandonment, and personalized recommendations.

**Key areas:**
- Exploratory data analysis
- Customer segmentation
- K-Means clustering
- Recommendation and review insights
- Visualization and business recommendations

[View Project](./05-Python-Market-Basket-Analysis/)

### 6. Capstone Project – Data Science PGC

**Tools:** Python, Pandas, NumPy, BeautifulSoup, Scikit-learn, Power BI

Completed an end-to-end book analytics project using web-scraped data from BooksToScrape. The workflow covered data acquisition, preprocessing, exploratory analysis, machine learning, and interactive dashboard development.

**Key areas:**
- Web scraping and data collection
- Data cleaning and feature engineering
- Exploratory data analysis
- Book price prediction using regression
- Power BI dashboard and business insights

[View Project](./06-Capstone-Project-Data-Science-PGC/)
