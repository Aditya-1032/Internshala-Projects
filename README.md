# Social Media Analytics for Strategic Branding

## Project Overview
This project was completed as part of my Data Science training with Internshala. It focuses on analyzing social media performance using Excel and a PepsiCo marketing dataset.

The objective is to evaluate social media engagement, platform performance, hashtag effectiveness, campaign outcomes, and follower growth to support data-driven marketing decisions.

## Tools & Skills
- Microsoft Excel
- Excel Power Query (Data Cleaning and Transformation)
- Data Cleaning and Preprocessing
- Excel Formulas and Functions
- Pivot Tables
- Data Analysis and Visualization
- Marketing Performance Analysis

## Project Objectives
- Analyze engagement rates across social media platforms.
- Identify high-performing posts and hashtags.
- Compare content performance across platforms.
- Evaluate campaign effectiveness and engagement uplift.
- Analyze follower growth and audience retention.
- Explore the relationship between advertising spend and follower growth.

## Dataset
The project uses the PepsiCo Marketing Dataset provided with the training assignment. The data covers social media posts, weekly engagement summaries, and campaign metadata.

## Project File
- `Social_Media_Analytics.xlsx` — Excel workbook containing the project analysis.
