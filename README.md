## Projects

### 01. Social Media Analytics for Strategic Branding

**Category:** Data Analytics  
**Tools:** Microsoft Excel, Excel Power Query, PivotTables, Excel Formulas

An Excel-based social media analytics project using a PepsiCo marketing dataset to explore engagement performance, content strategy, hashtag effectiveness, campaign outcomes, and audience growth.

**Key areas:**
- Data cleaning and transformation using Excel Power Query
- Social media engagement analysis
- Platform and content performance comparison
- Hashtag analysis and ranking
- Campaign effectiveness evaluation
- Follower growth and retention analysis
- Data visualization and business recommendations

**Project files:** [`01-Excel-Project`](./01-Excel-Project/)
